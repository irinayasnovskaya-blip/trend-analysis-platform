# Платформа для аналізу трендів

Стартова вебверсія для GitHub і Railway.

## Завантаження через браузер

1. Розпакуй архів.
2. У GitHub відкрий репозиторій `trend-analysis-platform` і натисни **Add file → Upload files**.
3. Перетягни всі шість файлів із розпакованого архіву в корінь репозиторію й натисни **Commit changes**.
4. У Railway відкрий новий запис у **Deployments**. Після успішного деплою відкрий свою чинну адресу Railway.

Railway запускає сервер через `npm start`. Сервер використовує порт, який передає Railway. Зовнішні пакети та API-ключі для стартової версії не потрібні.

## Що працює

- Розбір введеної обіцянки та складу за невеликим вбудованим довідником. Посилання зберігається лише в поточному результаті як джерело. Автоматичного завантаження відео немає.
- Базовий підбір догляду за типом, бажаним ефектом і необов’язковим віком.
- Розрахунок композиції у відсотках від концентрату, у грамах і у відсотках від готових парфумів.
- Пошук у стартовому каталозі й локальна історія версій формул. Формули зберігаються в браузері, без акаунтів та синхронізації.

Орієнтири запаху в каталозі описують можливий сенсорний ефект. Каталог не містить перевірених норм IFRA, алергенів, цін чи залишків постачальників.
